## 🌟 Overview

`buildmyapp` is an enterprise-grade CLI that generates fully configured, secure, and structured Node.js project boilerplates. 

Instead of spending hours wiring up authentication, logging, Docker, databases, linting, and environment validation from scratch, run one command and get a production-ready project tailored exactly to your architectural preferences. No more manual boilerplate setup. Start building features instantly.

## 🚀 Quick Start

### Installation

Install globally to use it anywhere:

```bash
npm install -g buildmyapp
```

Or run instantly using `npx` (no installation required):

```bash
npx buildmyapp my-awesome-api
```

### Create a Project

```bash
# Start the interactive setup
npx buildmyapp my-awesome-api

# You'll be prompted to provide project details and choose:
? Project description: A BuildMyApp generated project
? Author name: Jane Doe
? Application Port: 3000
? Select language: typescript
? Select framework: express
? Select architecture paradigm: class
? Select folder structure: enterprise
? Select database: postgres
? Select ORM/ODM: prisma
? Database URL (e.g., MongoDB Connection String): postgresql://postgres:postgres@localhost:5432/myapp
? Select authentication: jwt
? Select testing framework: jest
? Select package manager: npm
? Configure Redis cache setup? Yes
? Configure Swagger API documentation? Yes
? Configure Docker and Docker Compose setup? Yes

# Output
Successfully created project my-awesome-api!
```

### What Gets Generated?

After the CLI finishes, your project includes:

- A complete, scalable folder structure based on your choices
- All runtime and development dependencies installed securely
- Environment variables strictly configured (`.env.example` -> `.env`)
- Database connections and caching layers properly established
- Complete Authentication routing and middleware (if selected)
- Code quality tooling (ESLint + Prettier + Husky + lint-staged)
- Docker configurations and CI/CD pipelines ready for deployment

### Common Next Steps

```bash
cd my-awesome-api

# Run the app locally
npm run dev

# Or spin up the entire stack using Docker Compose
docker-compose up -d

# View the interactive API docs (if Swagger was selected)
# http://localhost:3000/api-docs
```

## 🔥 Features

### 🛡️ Authentication and Security
- Complete JWT-based authentication flow (Registration, Login, Auth Middleware).
- Secure password hashing with `bcrypt`.
- **Helmet** integration for HTTP security headers.
- Built-in API Rate Limiting to prevent brute-force attacks.

### 📐 Architecture and Structure
Choose between a lightweight **Simple** MVC layout for prototyping or a full **Enterprise** structure that includes:
- **Environment Safety:** `zod` schema validation guarantees your app never boots with missing or invalid `.env` variables.
- **Standardized Responses:** Extendable base controllers ensuring every API endpoint returns a consistent `{ meta, data }` format.
- **Global Error Handling:** Centralized middleware catching and formatting custom `ApiError` instances cleanly.

### 🌩️ Cloud and Infrastructure
- **Docker & Docker Compose:** Instantly containerized apps with multi-stage builds and pre-linked database services.
- **AWS S3 File Uploads:** Built-in `multer` and AWS SDK integration for direct-to-S3 file uploads.
- **Swagger Documentation:** Auto-generated interactive API docs (`/api-docs`) via `swagger-jsdoc`.

### 📝 Logging and Monitoring
- **Winston** structured logging.
- Formatted output for local development.
- JSON output for production log ingestion.

### ⚡ Performance and Database
- Relational and NoSQL support via **Prisma**, **Sequelize**, or **Mongoose**.
- Integrated **Redis** caching layer connection setup.
- Flexible support for Express or Koa frameworks.

### 🛠️ Developer Experience
- Immediate hot-reloading with `nodemon` or `ts-node`.
- Automated code formatting on commit via **Husky** and **lint-staged**.
- Instant testing setup using **Jest** or **Mocha**.
- Fully typed ecosystem for TypeScript users.

## 🚢 Deployment

### Docker

Every project can be containerized instantly if Docker support is selected:

```bash
# Build and start the app, database, and Redis cache in the background
docker-compose up -d

# Check logs
docker-compose logs -f app
```

### Cloud Ready

The generated multi-stage `Dockerfile` ensures your production images are exceptionally small (often under 100MB), making them perfect for deployment to AWS ECS, Google Cloud Run, Azure Container Instances, or DigitalOcean App Platform.
